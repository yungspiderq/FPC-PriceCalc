# 💰 PriceCalc — калькулятор комиссии и чистой цены

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Считает, сколько покупатель заплатит с учётом комиссии FunPay для выбранного
раздела, и какую цену поставить, чтобы получить нужную итоговую сумму. Использует
штатный метод FunPay `calc` — те же данные, что показывает сайт при создании лота.

## Возможности

- 🔢 **Прямой расчёт «цена → итог»**: вы вводите цену лота, плагин показывает
  комиссию, итоговую сумму для покупателя по каждому способу оплаты и минимальную
  цену раздела.
- 🎯 **Обратный расчёт «итог → цена»**: вы вводите, сколько должен заплатить
  покупатель, плагин считает, какую цену поставить в лот.
- 📂 **Список разделов берётся из ваших реальных лотов** — ничего вводить вручную
  не нужно. Поддерживаются обычные лоты и валюта (чипсы).
- ℹ️ **Минимальная цена раздела** — одним нажатием.
- 🧪 Кнопка **«Тест»** — быстрый расчёт по опорной цене.
- Расчёт ведётся живыми данными FunPay (`calc`), а не «приблизительной» комиссией.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-PriceCalc/main/price_calc.py -O plugins/price_calc.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/calc`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 📂 Выбрать раздел | Раздел из ваших лотов, для которого считать |
| 🔢 Цена → итог | Ввести цену лота → увидеть комиссию и итог для покупателя |
| 🎯 Итог → цена | Ввести желаемую итоговую сумму → увидеть цену лота |
| ℹ️ Мин. цена раздела | Минимальная цена, которую разрешает FunPay |
| 🧪 Тест | Быстрый расчёт по опорной цене (1000) |

Цену можно вводить с запятой или точкой, с пробелами и символом валюты
(`1500`, `1 500,50`, `1500 ₽` — всё распознаётся).

### Пример вывода прямого расчёта

```
💰 Расчёт комиссии
📂 Раздел: Аккаунты Steam
🏷 Цена лота: 1000 ₽
📈 Комиссия: 2.00%
⬇️ Мин. цена раздела: 50 ₽

Покупатель заплатит:
• СБП: 1020 ₽ (+20, 2.0%)
• Карта: 1050 ₽ (+50, 5.0%)
```

> Совет: сравнивайте **итоговую** цену для покупателя (с комиссией), а не цену лота —
> именно её видит покупатель в выдаче. В связке с
> [FPC-CompetitorWatch](https://github.com/yungspiderq/FPC-CompetitorWatch)
> удобно держать цену ниже конкурентов с учётом комиссии.

## Важно знать

- Плагин ничего не меняет в лотах — это только калькулятор.
- Разделы появляются после создания первого лота (берутся из профиля продавца).
- Данные о способах оплаты и комиссии возвращает FunPay; для разных разделов они отличаются.
- Настройки (последний раздел и цена): `storage/plugins/price_calc/settings.json`.

  ошибки `calc`, настройки). Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_price_calc.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_price_calc.py
  ```
